This folder was built with PyInstaller 6.22.3 from Python 3.13.17 (32-bit).

version, the license (SPDX identifier), where the source is, where the
bundled copy is in this folder, and which files in licenses\ hold the full
license texts. Licenses were checked against each package's PyPI metadata
and the license files shipped in its wheel.

https://www.gnu.org/licenses/gpl-3.0.txt, which LGPL-3.0 refers to.
